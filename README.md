# Mathematics & Physics Library

A GitHub Pages knowledge library built with Zensical. It brings the existing
Mathematics Library and Physics Library together under one address while
preserving their separate organization and colors.

## Preview locally

```bash
python -m venv .venv
```

On Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
zensical serve
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

Open **Settings → Pages**, choose **GitHub Actions** under **Build and
deployment**, and run the included workflow.
